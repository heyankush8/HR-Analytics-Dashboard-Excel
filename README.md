# 📊 HR Analytics Dashboard – Excel

An interactive **HR Analytics Dashboard built in Microsoft Excel** to analyze employee workforce composition and attrition patterns.

## 📌 Project Overview

This project analyzes an organization's employee data by combining information about:

* **Active Employees**
* **Employees who left the organization (Attrition)**

The dashboard provides a comparative view of employees across different HR dimensions.

## 📈 Key Analysis

The dashboard analyzes employees based on:

* 👥 Gender
* 🎓 Education Field
* 💼 Job Role
* 🏢 Department
* 🎂 Age Group
* 💍 Marital Status

For **Age Group, Education Field, Job Role, and Marital Status**, the visualizations combine both employee groups:

* 🔵 **Blue = Active Employees**
* 🟠 **Orange = Employees who left (Attrition)**

This makes it easier to compare the current workforce with employees who have left the organization.

The **Department analysis** is presented separately to show the overall employee distribution across departments.

## 🎯 Interactive Features

The dashboard includes interactive **Slicers/Filters** for:

* Education Field
* Department
* Gender

These allow users to dynamically filter the dashboard and analyze specific employee groups.
